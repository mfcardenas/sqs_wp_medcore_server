Bienvenido al Simulador MedCore

Este no es un juego simple de clics. Aquí tomarás decisiones reales de ingeniería de software aplicando estándares ISO en un entorno hospitalario crítico.

🎯 Tu objetivo: Liderar el desarrollo de un sistema de gestión hospitalaria completo, tomando decisiones técnicas fundamentadas y gestionando recursos limitados.

Sistema de Decisiones Complejas

Cada decisión tiene múltiples opciones con diferentes consecuencias:

  • Impacto técnico - Afecta la calidad del software
  • Costos - Modifica tu presupuesto disponible
  • Tiempo - Influye en los plazos de entrega
  • Stakeholders - Cambia la satisfacción de usuarios clave
⚠️ Cuidado: Las decisiones erróneas pueden llevar al fracaso del proyecto
